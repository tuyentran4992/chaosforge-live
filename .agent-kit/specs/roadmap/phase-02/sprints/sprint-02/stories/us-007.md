## Persona, nhu cầu và giá trị

Là **Ban Giám khảo Quốc tế & Twitch Streamer**, tôi muốn **mọi ý tưởng `!forge` (bằng tiếng Anh hoặc đa ngôn ngữ) thắng bình chọn hoặc gõ vào Judge Live Prompt được biên dịch thành cấu trúc JSON AST hợp lệ trong `< 2.5 giây` (có tích hợp API OpenAI / Codex kèm cơ chế local deterministic synthesis & bộ chặn ToS an toàn hiển thị bằng tiếng Anh)**, để **thấy rõ sức mạnh sinh logic thời gian thực của Codex mà tỷ lệ lỗi runtime trên sóng live luôn bằng `0%`**.

## Scope và non-goals

Scope:
- Xây dựng module **Codex Safe-Runtime AST Compiler**:
  - Hỗ trợ gọi OpenAI API (`Structured Outputs` / JSON Schema AST) khi có `OPENAI_API_KEY` trong biến môi trường, đồng thời có bộ **Deterministic Local AST Synthesizer** thông minh để đảm bảo phản hồi `< 2.5 giây` ngay cả khi Giám khảo chạy bản demo không cấu hình API key.
  - Tuyệt đối không dùng `eval()`; kiểm tra hợp lệ toàn bộ trường AST (`entity`, `gravity`, `collision`, `spawn_zone`, `sfx`, `duration`, `tags`) trước khi đưa vào engine vật lý.
  - Hiển thị trực quan quá trình biên dịch và cấu trúc AST bằng tiếng Anh trên khung **Codex Live Compiler (`420×272`)** kèm nhãn `AST SAFE VERIFIED`.
- Xây dựng **Bộ Chặn ToS (`ToS Safety Guard`)**:
  - Phát hiện từ khóa không an toàn/vi phạm điều khoản, chuyển sang trạng thái `6. Blocked` và tự động nạp bản vá an toàn **`RESCUE RUBBER DUCKS` (`duckfallback`)**.
- Quản lý **Kho Cartridge Hỗn Loạn Đã Lưu (`Saved Chaos Cartridges` — `#cartGrid`)**:
  - Nạp sẵn 6+ Cartridge mẫu (tên, mô tả và tags bằng tiếng Anh chuẩn), cho phép lưu bản vá mới vừa biên dịch từ Judge Prompt / Poll vào kho (`localStorage` + đồng bộ) và bấm triển khai lại bằng 1 chạm.

Non-goals:
- Không lưu hay commit API key cứng vào source code.

1. Nhập bất kỳ ý tưởng `!forge` hợp lệ nào vào `#judgePrompt` và bấm `COMPILE & DEPLOY <2.5S`: khung Codex Live Compiler trượt lên hiển thị AST hợp lệ và kích hoạt đúng hiệu ứng vật lý/Boss tương ứng trên màn hình trong `< 2.5 giây`, tỷ lệ lỗi `0%`.
2. Nhập prompt chứa từ khóa vi phạm ToS (hoặc bấm trạng thái `6. Blocked`): hệ thống hiển thị cảnh báo đỏ bằng tiếng Anh (`PROMPT BLOCKED BY TOS GUARD — DEPLOYING SAFE RUBBER DUCK FALLBACK`) và tự động chuyển sang bản vá an toàn *Rescue Rubber Ducks*.
3. Các Cartridge trong `#cartGrid` hiển thị bằng tiếng Anh, bấm triển khai ngay được lên màn hình và lưu giữ được bản vá mới do người dùng tạo.
