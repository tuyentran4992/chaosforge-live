# USER STORY — phase-02 / sprint-03 / us-009

Trạng thái tài liệu: Đang mở (`todo`). ID: `us-009`; thuộc [sprint-03](../SPRINT.md) và [phase-02](../../../PHASE.md).

## Persona, nhu cầu và giá trị

Là **Streamer & Khán giả Twitch**, tôi muốn **hệ thống hỗ trợ các thực thể meme nổi tiếng của văn hóa Twitch (`doge` cầm búa bonk, `popcat` há mồm theo nhịp), các hiệu ứng âm thanh meme hài hước (`bonk`, `bruh`, `boom`), chữ nổi reaction neon (`SKILL ISSUE!`, `RIGGED!`, `EMOTIONAL DAMAGE!`), và 2 Cartridge Meme mẫu sẵn sàng kích hoạt**, để **tăng tối đa tính giải trí và tính viral cho buổi livestream, mang đậm bản sắc văn hóa Twitch và tạo sự phấn khích tột cùng cho Ban Giám khảo TwitchCon**.

## Scope và non-goals

Scope:
- **Mở rộng AST Schema (`shared/ast-schema.js`):**
  - Mở rộng `entity` enum: bổ sung `'doge'` và `'popcat'` (thành `['duck', 'ball', 'star', 'boss', 'doge', 'popcat']`).
  - Mở rộng `sfx` enum: bổ sung `'bonk'`, `'bruh'`, `'boom'` (thành `['quack', 'pop', 'laser', 'bonk', 'bruh', 'boom', 'none']`).
- **Nâng cấp Natural Language Synthesizer (`shared/synthesize.js` & `server/openai.js`):**
  - Nhận diện từ khóa meme: `doge`, `cheems`, `bonk` ➔ entity `doge`; `popcat`, `cat`, `mèo` ➔ entity `popcat`.
  - Nhận diện SFX meme: `bonk` ➔ `bonk`; `bruh` ➔ `bruh`; `boom`, `vine boom`, `nổ` ➔ `boom`.
  - Duy trì triệt để khả năng loại trừ mệnh đề phủ định đa ngôn ngữ (ví dụ: `doge but without bonk sound`).
- **Đồ họa Vector 2D Canvas Meme (`client/overlay/artwork.js`):**
  - Thiết kế vector 2D thuần Canvas cho `doge` (khuôn mặt chó vàng nâu, tai tam giác, búa gõ cộp cộp) và `popcat` (khuôn mặt mèo trắng mồm há to tròn hài hước).
  - Tối ưu hóa hiệu năng render canvas bảo đảm tốc độ khung hình `≥ 60 FPS` trên canvas trong suốt `1920×1080`.
- **Tổng hợp Âm thanh Web Audio API Meme (`client/overlay/audio.js`):**
  - Thuật toán Web Audio tổng hợp không dùng file ngoài: `bonk` (âm gõ gỗ resonance), `bruh` (âm trầm hạ âm), và `boom` (Vine Boom âm trầm bass có reverb).
- **Chữ nổi Reaction Động (Floating Meme Badges):**
  - Khi streamer bấm Spacebar Panic Clear hoặc va chạm: hiển thị hiệu ứng chữ nổi phóng to mờ dần (`SKILL ISSUE!`, `RIGGED!`, `EMOTIONAL DAMAGE!`) với màu sắc neon rực rỡ trong 1.5 giây.
- **Cartridges Meme Sẵn Có:**
  - Bổ sung 2 Cartridge Meme vào danh sách preset: *"Bonk Doge Hammer Storm"* và *"Popcat Chorus Hype"*.
- **Kiểm thử tự động & Tiêu chuẩn mã nguồn:**
  - Cập nhật và bổ sung test cases trong `test/*.test.js` để bao phủ 100% schema và synthesizer mới.
  - Đảm bảo 100% file mã nguồn đều tuân thủ nghiêm ngặt `≤ 250` dòng vật lý.

Non-goals:
- Không thay đổi kiến trúc kết nối WebSocket Twitch IRC hay giao thức signaling giữa streamer deck và overlay.

## Acceptance quan sát được

1. Gõ prompt tự nhiên chứa từ khóa meme (ví dụ: `!forge bonk doge storm with boom sound` hoặc `!forge popcat`) được biên dịch chính xác sang AST với entity `doge` / `popcat` và SFX tương ứng trong `< 300ms`.
2. Màn hình Canvas Overlay hiển thị chính xác đồ họa vector 2D của `doge` và `popcat` chuyển động vật lý mượt mà (`≥ 60 FPS`), không lỗi runtime.
3. Âm thanh Web Audio API phát chính xác âm sắc `bonk`, `bruh`, `boom`.
4. Khi Panic Clear hoặc va chạm, hiệu ứng chữ nổi `SKILL ISSUE!`, `RIGGED!` hoặc `EMOTIONAL DAMAGE!` hiển thị mượt mà.
5. Toàn bộ test suite tự động pass 100% và 100% file mã nguồn đều `≤ 250` dòng vật lý.
